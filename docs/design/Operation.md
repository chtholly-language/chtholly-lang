## 运算符

Chtholly目前支持下述运算符

| 运算符 | 用途与类型 |
| --- | --- |
| 一元 `+ -` | 数值的正号、取负 |
| `+ - * /` | 同型整数或同型浮点的四则运算 |
| `%` | 同型整数的余数 |
| `~`、`&`、`\|`、`^` | 整数位运算；`^` 是异或 |
| `<< >>` | 整数位移，右侧计数可以是不同整数类型 |
| `< <= > >=` | 同型数值的大小比较，结果为 bool |
| `== !=` | 同型数值或 bool 的相等比较 |
| `!`、`&&`、`\|\|` | bool 取反、短路与、短路或 |
| `as 类型` | 显式保值转换，见 [类型转换](As.md) |
| `copy`、`move` | 显式所有权，顾名思义 |

### 优先级

运算优先级从高到低为：

```text
调用、字段、数组下标
前缀 + - ! ~ copy move
as 类型
* / %
+ -
<< >>
&
^
|
< <= > >=
== !=
&&
||
```
