## 运算符

Chtholly目前支持下述运算符

| 类别 | 运算符 | 适用类型 | 含义 |
| --- | --- | --- | --- |
| 一元正负 | `+x`、`-x` | 整数、浮点 | 保持数值、取负 |
| 加减乘除 | `+ - * /` | 整数、浮点 | 数值运算 |
| 余数 | `%` | 整数 | 整数除法的余数 |
| 按位取反 | `~x` | 整数 | 固定位宽内逐位取反 |
| 按位运算 | `&`、`\|`、`^` | 整数 | 按位与、或、异或 |
| 位移 | `<< >>` | 整数 | 左移、右移 |
| 大小比较 | `< <= > >=` | 整数、浮点 | 结果为 bool |
| 相等比较 | `== !=` | 整数、浮点、bool | 结果为 bool |
| 逻辑取反 | `!x` | bool | 真假取反 |
| 逻辑运算 | `&&`、`\|\|` | bool | 短路与、短路或 |
| 显式转换 | `as Type` | 数值类型之间 | 要求保留源值 |
| 赋值 | `=` | 可写的局部位置 | 先求右侧，再写入左侧 |

### 优先级

运算优先级从高到低为：

```text
直接函数调用
一元 + - ! ~
as Type
* / %
+ -
<< >>
&
^
|
< <= > >=
== !=
&&
||
```
