# 编译器命令行参考

## 调用形式

```text
chthollyc <input.cns> -o <output.exe>
chthollyc --help
chthollyc --version
```

- 一次调用接受一个输入和一个 `-o` 输出路径。重复选项、额外输入及未知选项是用法错误。
- `--help`、`--version` 单独使用。
- `--` 结束选项解析，其后按输入路径处理；`-o` 须在 `--` 前提供。以短横线起始的输出名可写成带目录的路径，例如 `./-result.exe`。
- 输出父目录必须已经存在；路径含空格时由调用者正常加引号。
- 编译器负责生成并链接程序，不自动执行产物。

当前不提供 `-O2`、`-g`、PDB、仅语法检查、IR 转储或多文件编译选项。

## 退出码与诊断

| 进程 / 情形 | 退出码 |
| --- | --- |
| 编译器成功，包括帮助和版本 | 0 |
| 源码、I/O、代码生成、外部工具或发布失败 | 1 |
| 编译器命令行用法错误 | 2 |
| 生成程序正常结束 | 源码 main 的返回值，独立于编译器退出码 |

正常编译保持安静，错误写入 stderr。源码诊断的行、列从 1 开始，列按 UTF-8 字节计数；初始 BOM 占 3 个字节。诊断文字用于定位问题，当前没有 JSON 诊断接口。

生成程序返回 42 不表示编译失败。

## 依赖选择

配置时，Preset 从 `CHTHOLLY_LLVM_DIR` 读取 LLVM CMake package 路径；也可以显式提供 `-DLLVM_DIR=...`。构建系统要求 LLVM 18.1.8，并从选定安装定位匹配的 clang-cl 和 lld-link。

编译器运行时若设置 `CHTHOLLY_LLVM_BIN`，使用其中的工具并核对版本；显式无效目录不回退到其他安装。未设置时使用配置阶段记录的工具目录。MSVC CRT 和 SDK 环境仍须由开发者准备。

## 输出发布

临时目标文件、链接产物和工具日志放在输出父目录下的独立临时子目录。只有本次链接成功且目标检查通过，才发布 exe；失败保留原有主产物。

输入输出指向同一个文件时拒绝，包括硬链接别名；输出目标为目录或符号链接时也拒绝。清理只处理本次创建的已知临时文件，不递归清理用户输出目录。
